Guess the number

I made a guess the number game in Python that
has three separate difficulties the user could
choose.
I also did a lot of data validation in order to make
sure my code almost always works.
The first difficulty is 1-100. The second difficulty
is user chosen highest to lowest but whole
numbers.
Finally, the third difficulty is also user chosen
but to one decimal place.

MAGS Quiz

I made a MAGS related quiz with Python using
lists, mathematics logic, conditions and data
validation for every single input.
First the user is asked to choose a subject.
Next they get to choose either of 2 modes of
questions.
Then if the user chooses a singular question the
user chooses one.
Once the user answers all the questions they get
given a grade and a time that it took.
